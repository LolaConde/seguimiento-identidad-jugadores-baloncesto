La lectura de dorsales se añade como una capa adicional para obtener información que permita corregir los errores del tracker base y mejorar el seguimiento. 

En el notebook `OCR_explicacion.ipynb` se encuentra la explicación de cómo se realiza la lectura de dorsales, así como la selección de un OCR.

En el notebook `obtener_predicciones_OCR.ipynb` se encuentra el código utilizado para obtener las predicciones de los dorsales.

En el notebook `obtener_metricas_graficas_OCR.ipynb` se encuentra el código para obtener las métricas y gráficas para seleccionar el OCR finalmente utilizado, así como el código en el que se selecciona la cadena que se considera la "predicción del dorsal" cuando un OCR predice varias cadenas en una misma imagen.
